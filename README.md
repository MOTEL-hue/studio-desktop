# אולפן שידור - תוכנה עצמאית למחשב (Windows)

תוכנה שמכילה את האולפן בתוכה. **בלי אתר ובלי כניסה לחשבון**: מתקינים ופותחים. עובדת גם בלי אינטרנט.

- **אולפן הקלטות בתוך התוכנה:** כפתור "🎙️ אולפן הקלטות" בראש האולפן - הקלטת שירים, מנגנייה, אפקטים, ניקוי רעשים, תיקון זיופים וייצוא ל-WAV/MP3 (בלי יוטיוב, דרייב וקו טלפון, שעוברים דרך האתר).
- **סמל נפרד "אולפן הקלטות"** (שולחן העבודה, תפריט התחל, שורת המשימות), ופתיחת פרויקט ‎.mzproj בלחיצה כפולה.
- **קובץ לוג אוטומטי:** עזרה ← פתיחת קובץ הלוג (הפעלות, עדכונים, שגיאות וקריסות).
- **סיסמה לתוכנה (לא חובה):** אולפן ← סיסמה לתוכנה.
- **מקשי קיצור כלליים** שעובדים גם כשחלון אחר בחזית (Ctrl+Alt+חצים, Ctrl+Alt+1-9, ואפשר גם נאמפד).
- אישור אוטומטי של מצלמה, מיקרופון ו-MIDI, ושיתוף מסך עם תפריט בחירה קטן.
- **חלון ההצגה נפתח במסך השני** במסך מלא.
- חלון שלא מואט כשהוא ברקע.
- **עדכון אוטומטי של התוכנה** מבפנים: בכל הפעלה היא בודקת גרסה חדשה, מורידה, ושואלת אם להפעיל מחדש.

## הורדה
[StudioSetup.exe](https://github.com/MOTEL-hue/studio-desktop/releases/latest/download/StudioSetup.exe)

## מקור האולפן
התיקייה `app/` נוצרת מקבצי האולפן באתר (`desktop-app/tools/make_bundle.py` במאגר virtual-chat) ולא עורכים אותה ידנית.

## בנייה
Actions ← Windows installer ← Run workflow, ורושמים מספר גרסה כדי לפרסם.
