# אולפן שידור - תוכנה למחשב (Windows)

תוכנה שעוטפת את דף האולפן של האתר (`/studio/`) בחלון משלו, ומוסיפה מה שדפדפן לא יכול:

- **מקשי קיצור כלליים** שעובדים גם כשחלון אחר בחזית (Ctrl+Alt+חצים, Ctrl+Alt+1-9, ואפשר גם נאמפד).
- אישור אוטומטי של מצלמה, מיקרופון, MIDI ושיתוף מסך (עם תפריט בחירה קטן).
- **חלון ההצגה נפתח במסך השני** במסך מלא.
- חלון שלא מואט כשהוא ברקע.
- **עובדת גם בלי אינטרנט** אחרי הפעם הראשונה. האולפן עצמו נטען מהאתר, ולכן **מתעדכן לבד** עם כל שדרוג של האתר.
- התוכנה עצמה מתעדכנת מההורדות בגיטהאב.

## הורדה
[StudioSetup.exe](https://github.com/MOTEL-hue/studio-desktop/releases/latest/download/StudioSetup.exe)

בפעם הראשונה התוכנה שואלת את כתובת האתר. אחר כך נכנסים לחשבון באתר כרגיל.

## בנייה
Actions ← Windows installer ← Run workflow, ורושמים מספר גרסה כדי לפרסם.
